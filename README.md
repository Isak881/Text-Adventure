# Text Adventure

## Beskrivning
I detta spelet så ska spelaren välja alternativ 
som leder spelaren till diamanterna i gruvan.
## Funktioner
Spelaren väljer alternativ genom att välja en siffra som programmet ber spelaren att välja.
## Installation
1. Klona eller ladda ner projektet.
2. Se till att Python är installerat på din dator.

Lycka till!
